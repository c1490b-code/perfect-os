# MUSIC/SP Architecture

MUSIC/SP support is organized as a guest operating-system layer.

PERFECT-OS does not replace or redistribute MUSIC/SP.

The integration layer provides:

1. emulator detection
2. guest configuration
3. IPL configuration
4. disk/image management
5. terminal integration
6. documentation
7. future AI-assisted mainframe tooling

Future integration can expose MUSIC/SP through the PERFECT-OS
mainframe shell and AI administration layer.
